Quantum Cats - HTML version

To play on this computer: extract the whole zip (don't open index.html from inside
the zip preview), then double-click index.html in the extracted folder.

To put it online: upload the whole folder to any web server (https recommended).
Optional hardening for servers: send this Content-Security-Policy header:
default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; font-src data:; img-src 'self' data:; media-src 'self' blob:; connect-src 'self'; object-src 'none'; base-uri 'none'; form-action 'none'

Keyboard: Space to aim, arrows to adjust angle/power, Space to launch, Esc for options.
